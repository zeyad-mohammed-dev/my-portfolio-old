# My Portfolio

A modern, responsive portfolio website showcasing backend development expertise, projects, and technical skills. Built with React, TypeScript, and modern web technologies with a strong focus on performance, clarity, and user experience.

---

## 🚀 Project Overview

This is a professional portfolio website designed for backend developers.  
It presents backend-focused projects, technical skills, and development experience in a clean, calm, and user-friendly interface with subtle motion and modern UI patterns.

---

## ✨ Features

### Core Features
- **Responsive Design**: Fully responsive layout across desktop, tablet, and mobile devices
- **Dark Mode**: Built-in dark theme with smooth and comfortable transitions
- **Subtle Animations**: Carefully implemented animations using Framer Motion to enhance UX without distraction
- **Modern UI Components**: Consistent and accessible components built with shadcn/ui
- **Glassmorphism Accents**: Light glass-card styling used selectively for visual depth

### Portfolio Sections
- **Hero Section**: Clear introduction with primary call-to-action buttons
- **About**: Background and backend development focus
- **Skills**: Clear presentation of technical skills and backend-focused technologies
- **Projects**: Backend project showcase with concise descriptions
- **Contact**: Direct contact methods and social links
- **Resume Download**: Direct PDF resume download

### Technical Highlights
- **Type-Safe Codebase**: Built with TypeScript for improved maintainability
- **Performance-Aware**: Optimized asset loading and efficient rendering
- **SEO Friendly**: Semantic HTML structure with basic meta tag setup
- **Accessibility-Aware**: Semantic markup and keyboard-friendly navigation

## 🚀 Setup

### Prerequisites
- **Node.js** (v18 or higher)
- **npm** or **yarn**

### Installation

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd my-portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   yarn install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   # or
   yarn dev
   ```

4. **Open in browser**
   ```
   http://localhost:8080
   ```

## 📜 Scripts
